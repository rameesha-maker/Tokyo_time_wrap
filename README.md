# Tokyo_time_wrap

What does it do:
it is a 2d game where we set our player into different time zones of tokyo 
first is the feudilistic era where their are a few challenges which he had to surpass in order to get to the time jump kind of thing where he then gets to the second era the present era,he there also face some challenges in order to get to the time jump and then the futuristic era with the future of tokyo like in shinchan or doraemon
Also to face these xchallenges he will get powers like bamboo copter to get to the platforms that are above normal range aand time machine so that he can see where he made the mistake

what does it currently do:
for now only the player can move up down ,back,and forward . also the platforms are enabled where we can move and then at the end is the time jump that takes you to the next era the futuristic and after the futuristic era .

Technology used:
i used pygame to build this .and used OOP(object oriented programming),which i recently learned to make this game.
